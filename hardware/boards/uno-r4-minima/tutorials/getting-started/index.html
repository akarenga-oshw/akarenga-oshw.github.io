    Arduino IDE UNO R4 Minima インストール

    Akarenga UNO 導入手順

    Arduino IDEを使い、Akarenga UNOの開発環境を導入して、LED点滅（Blink）とシリアル通信を確認するまでの手順です。

    ボードパッケージ：Akarenga UNO R4 Boards 1.5.3-xtal2
    ボード名（IDEでの表示）：Arduino UNO R4 Minima（Akarenga UNO R4 Boards内）

    1. この手順でできること

    この手順を最後まで行うと、次の状態になります。

    • Arduino IDEからAkarenga UNOを選択できる
    • Akarenga UNO用のスケッチをコンパイルして書き込める
    • ボード上のLEDを1秒間隔で点滅させられる
    • シリアルモニターでAkarenga UNOからの文字を確認できる

    Note

    Akarenga用ボードパッケージには、12 MHzメイン水晶と32.768 kHz RTC水晶を使うためのCoreが含まれます。通常の利用者が水晶用のソースコードや設定ファイルを書き換える必要はありません。

    2. 必要なもの

    • Akarenga UNO本体
    • Akarenga UNOとパソコンを接続できるUSBデータ通信対応TypeCケーブル
    • Windows 10以降、macOS 10.15以降、または64ビットLinuxのパソコン
    • インターネット接続
    • Arduino IDE 2

    USBケーブルに注意

    充電専用のUSBケーブルでは書き込みできません。データ通信に対応したケーブルを使用してください。

    3. Arduino IDE 2をインストールする

    1. Arduino公式ダウンロードページを開きます。
    2. 使用しているOSに合ったArduino IDE 2の安定版をダウンロードします。
    3. ダウンロードしたファイルを開き、画面の案内に従ってインストールします。
    4. Arduino IDEを起動します。

    OSごとの基本操作は次のとおりです。

    OS インストール方法
    Windows .exeを実行し、インストーラーの案内に従う
    macOS .dmgを開き、Arduino IDEを「アプリケーション」へ移動する
    Linux AppImageに実行権限を付けて起動する

    Note

    この手順書ではArduino IDE 2を使用します。IDE 1.8.19はLegacy版のため、画面やメニューの位置が異なります。

    Note

    操作GIFはWindows 11・Arduino IDE 2.3.10の画面です。操作の要所を順に表示し、待ち時間を短縮しています。GIFをクリックすると元のサイズで表示できます。

    4. 公式のArduino UNO R4 Boardsをインストールする

    現在のAkarenga開発版は、コンパイラなどのツールチェーンをArduino公式パッケージから利用します。先に公式のUNO R4用パッケージをインストールしてください。

    1. Arduino IDE左側のボードマネージャーアイコンをクリックします。

    2. 検索欄に次を入力します。

      Arduino UNO R4 Boards

    3. Arduino公式のArduino UNO R4 Boardsを選び、インストールをクリックします。

    4. Windowsでドライバーの確認画面が出た場合は、Arduino公式パッケージのインストールに伴うものか確認し、はいを選びます。
    5. パッケージ名の下にinstalledと表示されるまで待ちます。

    5. AkarengaのボードマネージャーURLを登録する

    5.1 設定画面を開く

    • Windows／Linux：ファイル → 基本設定
    • macOS：Arduino IDE → 設定

    5.2 URLを追加する

    1. 追加のボードマネージャーのURLを探します。
    2. 入力欄の右側にあるボタンを押し、URL一覧を開きます。

    3. 次のURLを1行で貼り付けます。

      https://akarenga-oshw.github.io/arduino-board-index/package_akarenga_index.json

    4. すでに別のURLが登録されている場合は削除せず、新しい行へ追加します。

    5. OKを押してURL一覧を閉じ、もう一度OKを押して設定を保存します。

    6. Akarenga用ボードパッケージをインストールする

    1. Arduino IDE左側のボードマネージャーを開きます。

    2. 検索欄に次を入力します。

      Akarenga

    3. Akarenga UNO R4 Boardsを選びます。

    4. バージョン欄を確認し、インストールをクリックします。
    5. Windowsでドライバーの確認画面が出た場合は、Akarenga用パッケージのインストールに伴うものか確認し、はいを選びます。
    6. パッケージ名の下にinstalledと表示されるまで待ちます。

    バージョンについて

    2026年11月1日時点の開発版では、表示バージョンは1.5.3-akarenga.1です。今後バージョンが更新された場合は、プロジェクトから特別な指定がない限り新しい安定版を使用し、実際に使ったバージョンを記録してください。

    7. ボードとポートを選択する

    1. Akarenga UNOをUSBケーブルでパソコンに接続します。
    2. Arduino IDE上部のツール → ボードを開きます。
    3. Akarenga UNO R4 Boards → Akarenga UNO R4 Minimaを選びます。
    4. Akarenga UNOに対応するポートをツール → ポートから選びます。

    ポート名の例は次のとおりです。実際の表示は環境により異なります。

    OS ポート名の例
    Windows COM3、COM4
    macOS /dev/cu.usbmodem...
    Linux /dev/ttyACM0

    8. Blinkを書き込む

    8.1 サンプルを開く

    Arduino IDEのメニューから、次を選びます。 ファイル > スケッチ例 > 01.Basics > Blink

    次の内容と同様のスケッチが開きます。

    void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}

    8.2 書き込む

    1. Arduino UNO R4 Minimaを選択していることを確認します。
    2. 選択中のポートを確認します。
    3. Arduino IDE左上の書き込みボタン（右向き矢印）をクリックします。
    4. 画面下部に書き込み完了の表示が出るまで待ちます。
    5. ボード上の内蔵LEDが約1秒ごとに点灯・消灯することを確認します。

    LEDが点滅すれば、コンパイル、USB書き込み、メインクロック、基本的なArduino関数が動作しています。

    9. シリアルモニターを確認する

    新しいスケッチへ次を貼り付けます。

    void setup() {
  Serial.begin(115200);

  unsigned long start = millis();
  while (!Serial && millis() - start < 5000) {
    // シリアル接続を最大5秒待つ
  }

  Serial.println("Akarenga UNO serial test");
}

void loop() {
  Serial.print("millis = ");
  Serial.println(millis());
  delay(1000);
}
    1. スケッチを書き込みます。
    2. Arduino IDE上部のツール → シリアルモニタを開きます。
    3. 通信速度を115200 baudに設定します。
    4. millis = ...が約1秒ごとに表示されることを確認します。

    Tip

    最初のAkarenga UNO serial testが見えない場合でも、millisの値が増え続けていればシリアル通信は正常です。シリアルモニターを開いたまま再起動すると、最初の行も確認しやすくなります。
